# Playbooks (SOPs) — Respuesta a Incidentes

Procedimientos operativos estándar para los escenarios más comunes del SOC. Cada playbook sigue el ciclo NIST SP 800-61r2: **Preparación → Detección → Contención → Erradicación → Recuperación → Lecciones aprendidas**.

| Playbook | Escenario cubierto |
|----------|--------------------|
| [brute-force-response.md](brute-force-response.md) | Ataques de fuerza bruta a autenticación |
| [malware-response.md](malware-response.md) | Malware endpoint (trojan, RAT, etc.) |
| [suspicious-outbound.md](suspicious-outbound.md) | Beaconing / exfiltración |
| [ransomware-response.md](ransomware-response.md) | Ransomware — crisis mode |
| [phishing-response.md](phishing-response.md) | Correo malicioso / credencial comprometida |
